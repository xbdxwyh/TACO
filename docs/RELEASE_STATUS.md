# Release status

This is a private preparation for review, hosted in Yihao Wang's personal
repository: https://github.com/xbdxwyh/TACO. It has not been publicly released.

The authors have not selected licenses for the code, dataset or their own
checkpoints. Accordingly, no default LICENSE file or open-source grant has
been added. Any notices for third-party code remain applicable. External
model weights are not redistributed here.

Before public release, settle the code/data/checkpoint licenses, final citation,
repository URL and any archival dataset identifier. The paper's availability
statement should then point to that actual release. The dataset and small
first-party checkpoints can be hosted together with the code; no separate
image hosting is required for this text-only version.

Original working directories, experimental protocols and outputs are preserved.
The package-relative core has provenance hashes in `provenance/core_sources.json`.
The clean runtime replaces path-specific historical experiment drivers, without
changing the frozen controller or mathematical scoring rules.
